# 机械限位标定（App 内）

用于 J1 零点改变后重新测量机械限位。标定模式会**绕过软限位检查**，只允许手动低速点动；不会自动撞限位。

## 步骤

1. 连接机械臂（端口可自动识别；也可手动选择 `/dev/cu.usbmodem*` 或 `COM*`）。
2. 先确认当前姿态与 App 角度一致。若 J1 零点已改变，先在“关节控制”里对 J1 执行一次“设为零点”，否则测出的限位会相对错误的零点。
3. 侧边栏 → **关节控制** → **限位标定…**。
4. 选择关节，速度建议 `0.10 RPM` 或更低。
5. 用 `-5°/-1°` 点动接近负限位；到机械限位后立即停，不要硬顶。
6. 点 **记录当前为最小**。
7. 用 `+1°/+5°` 反向点动到正限位，点 **记录当前为最大**。
8. 点 **保存限位到配置**。
9. 若中途触发堵转保护，先点 **清除保护**，再继续。

## 配置写入位置

- 源码运行：`arm/config/joints.json`
- macOS App：`~/Library/Application Support/Episode1/joints.json`
- Windows App：`%APPDATA%\Episode1\joints.json`

App 内保存后立即生效；CLI `armctl.py` 仍读取项目里的 `arm/config/joints.json`，如需 CLI 同步，请把新值也写入该文件。

## 安全

- 标定模式只用于**手动低速**点动，不要用它做正常运动。
- 到机械限位就停；堵转保护不是硬限位。
- 标定前确认 12–32 V 供电、底座固定、线缆有余量。
